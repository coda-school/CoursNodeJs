# Objectifs pédagogiques
- Comprendre ce qu’est Node.js, son fonctionnement et ses usages côté serveur dans des architectures modernes   
- Initialiser un projet Node.js, installer les dépendances avec npm et structurer le projet
- Créer une API REST basique à l'aide d'Express en implémentant les méthodes GET, POST, PUT, DELETE, et en respectant les conventions RESTful
- Gérer les erreurs serveur, structurer les messages de réponse et assurer un comportement cohérent de l’API en cas de dysfonctionnements
- Utiliser des outils de développement pour tester, observer l’API (curl, Postman) et mettre en place une base de logs
- Identifier les leviers d’optimisation pour réduire l’empreinte environnementale d’une API (ex: limitation des appels inutiles ou la réduction des dépendances)
